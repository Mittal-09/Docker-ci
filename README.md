 Flask App CI/CD Pipeline

This project demonstrates how to build and run a Python Flask application using Docker and automate the workflow with GitHub Actions. It helped me understand the basics of Docker and CI/CD automation.

## Features

✅ Flask application using Python

✅ Docker image and container creation

✅ Automated workflow using GitHub Actions

✅ Code management using Git and GitHub

✅ Basic CI/CD pipeline implementation

## Tech Stack

- Python (Flask)
- Docker
- Git & GitHub
- GitHub Actions
- YAML

## How to Use

1. Clone the repository:

```bash
git clone https://github.com/Mittal-09/Docker-ci.git
```

2. Navigate to the project folder:

```bash
cd flask-app
```

3. Build the Docker image:

```bash
docker build -t flask-app .
```

4. Run the Docker container:

```bash
docker run -p 5000:5000 flask-app
```

5. Open your browser and go to:

```text
http://localhost:5000
```
